# CampusGigs Phase G

This release expands CampusGigs' service directory for Nigerian schools and
neighbourhoods. It does not enable any payment or transfer functionality.

## Included

- 28 stable service categories, including barbing, hairdressing, electrical
  services, phone repair, tailoring, laundry, plumbing and catering.
- Search handles multi-word terms, common Nigerian trade words, provider names,
  listing categories and campus/locality text. State/institution filters remain
  strict and cross-state browsing requires a warning in the public UI.
- An applicant choosing "Campus" must have a recognised school in their profile;
  new gigs must match the provider's confirmed state and optional institution.
  Campus information is edited using the canonical school picker, not the
  free-text profile bio form.
- Account-specific notification inbox (read/read-all) for new followers,
  requests, booking decisions and provider application review. These are
  generated by D1 triggers to avoid duplicate notifications on retried writes.
- Follow/unfollow methods are allowed by the API and its CORS preflight.

## Operational notes

- Apply `apps/api/migrations/0007_phase_g_notifications.sql` after migration 0006.
- Firebase Authentication and existing Cloudflare D1/R2 bindings remain intact.
- Notifications are **in-app**; this release does not claim push delivery when
  the app is closed or the browser is offline.
- Booking requests remain service inquiries; all checkout, payouts and refunds
  are **disabled**.
- Provider ratings/reviews are deferred until a trustworthy service-completion
  confirmation flow exists, to avoid unverifiable ratings.
